## HyperCopy 云端仓库

### 配置上传

链接跳转配置放link文件夹，口令配置放text文件夹

### 命名规则

`配置名称_应用包名.json` 如 `B站国际版视频_com.bilibili.app.in.json`

配置名称仅云端仓库下载界面可见，具体名称见配置里的字段。
